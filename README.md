# MENXO

MENXO clothing store — storefront (`index.html`), checkout (`checkout.html`), admin panel (`admin.html`) and moderator panel (`mod.html`), backed by Supabase.

Setup steps (Bangla): see `HOSTING.md`. Database setup: run `supabase-setup.sql` (shipped next to this folder, not inside the website) in the Supabase SQL Editor. Do not deploy that file.
